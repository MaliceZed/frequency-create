# Frequency for Create

**Add customizable frequency items for Create's Redstone Link!**

![NeoForge](https://img.shields.io/badge/NeoForge-21.1.190+-blue)

## 📖 Overview

Frequency for Create is a quality-of-life addon for the Create mod that adds a complete set of symbol items for configuring Redstone Link frequencies.

## ✨ Features

### 🔢 Complete Symbol Set
- **10 Digit Symbols** (0-9) - For numeric frequencies
- **26 Letter Symbols** (A-Z) - For alphabetic frequencies  
- **4 Arrow Symbols** (↑↓←→) - For directional indicators
- **1 Empty Symbol** - For clearing frequency slots

### 🎨 Intuitive GUI
Right-click any symbol item to open an elegant swap interface where you can:
- Browse all available symbols organized by category
- Instantly swap your held symbol with any other
- See clear visual categories: Digits, Letters, Symbols

### ⚡ Seamless Integration
- Works perfectly with Create's Redstone Link
- Symbols stack up to 8 items
- Uncommon rarity with custom textures
- Fully localized (English & Russian)

## 📦 Installation

1. Download the latest release from [Releases](https://github.com/yourusername/frequency-create/releases)
2. Install [NeoForge](https://neoforged.net/) 21.1.190 or higher
3. Install [Create](https://modrinth.com/mod/create) mod
4. Place the downloaded `.jar` file in your `mods` folder
5. Launch Minecraft!

## 🎮 How to Use

1. Craft or obtain symbol items (recipes included)
2. Right-click any symbol to open the swap GUI
3. Click on any symbol to swap your current item
4. Use symbols to configure your Redstone Link frequencies

## 🔧 Building from Source

```bash
# Clone the repository
git clone https://github.com/yourusername/frequency-create.git
cd frequency-create

# Build the mod
./gradlew build

# The compiled jar will be in build/libs/
```
